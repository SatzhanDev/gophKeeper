# GophKeeper

Клиент-серверный менеджер паролей: надёжное хранение логинов/паролей, произвольных
текстовых и бинарных данных, данных банковских карт с поддержкой синхронизации
между несколькими клиентами одного пользователя.

Проект реализуется по ТЗ курса Yandex Practicum "Go-разработчик" (диплом).

## Статус

В разработке. Список инкрементов (PR) и их статус — см. `docs/roadmap.md` (появится позже)
или таск-лист в текущей сессии разработки.

## Стек

- Go 1.25
- gRPC — протокол взаимодействия клиент-сервер
- PostgreSQL — хранилище сервера
- JWT — аутентификация
- cobra — CLI-клиент
- grpc-gateway — REST/Swagger поверх gRPC API (опционально, в конце)

## Структура репозитория

```
cmd/server     — точка входа сервера (main.go)
cmd/client     — точка входа CLI-клиента (main.go)
internal/server — бизнес-логика сервера
internal/client — бизнес-логика клиента
internal/pkg    — общий код (модели, крипто-утилиты)
api/            — .proto описания gRPC API
migrations/     — SQL-миграции базы данных
```

## Сборка и запуск

Будет описано по мере готовности сервера и клиента (см. Makefile).

```
make build   # собрать server и client
make test    # прогнать юнит-тесты
```
